# CommonGround — draft entry
Tagline: Different tastes. One good night.

CommonGround is a group movie-night negotiation agent. Each person selects a favorite movie; Qloo provides a distinct taste-grounded candidate list for that person. A deterministic negotiation step protects the least-served participant, compares that choice with an average-first baseline, and produces an inspectable decision trace. Missing evidence is explicit, and rank utility is never presented as a probability of enjoyment.

Built with Python, browser JavaScript, Qloo Search and Insights, and Codex assistance. The prototype uses no LLM-generated film facts. Its differentiator is separating individual taste retrieval from transparent group aggregation.

Current status: live API access and public runtime deployment pending. Do not submit this draft as a completed Qloo integration until a real hosted run succeeds.
